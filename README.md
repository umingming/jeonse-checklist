# 전세 체크리스트

전세 매물 방문 시 사용하는 모바일 체크리스트 웹앱.

**사용하기**: https://umingming.github.io/jeonse-checklist/

## 기능

- 매물 기본 정보 입력 (주소, 보증금, 월세, 관리비, 계약기간, 입주일, 메모)
- 4개 카테고리 체크리스트 (OK / 불량 / N/A 선택)
  - 집 상태: 누수, 곰팡이, 벽, 바닥, 창문, 도배/장판, 잠금장치
  - 시설/편의: 수압, 온수, 난방, 환기, 콘센트, 인터넷, 가스레인지, 에어컨, 세탁기
  - 주변 환경: 대중교통, 편의점, 소음, 일조량, 보안, 주차
  - 기타: 반려동물, 전입신고, 등기부등본
- 이미지로 저장 (PNG 다운로드)
- 자동 저장 (localStorage)

## 기술 스택

- HTML / CSS / JavaScript (빌드 도구 없음)
- html2canvas (CDN)
- GitHub Pages 배포
